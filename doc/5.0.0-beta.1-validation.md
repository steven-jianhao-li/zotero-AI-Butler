# 5.0.0-beta.1 发布前验收

本轮测试对象是整合 PR #421、#422、#423、#424 和现有 dev 开发的 `5.0.0-beta.1` 候选包。版本号已准备；人工验收通过后，由维护者发布。

## 改动范围

| 来源   | 本轮需要关注的行为                                                          |
| ------ | --------------------------------------------------------------------------- |
| #421   | PDF 缓存恢复、中文路径提取、取消、失败诊断与错误详情复制                    |
| #422   | 教程跨窗口导航、设置可见性、当前 PDF 的明确入队确认                         |
| #423   | 侧栏高度约束、底部可达性、内外层滚轮交接                                    |

## 人工测试清单

先在实际使用的 Zotero 版本完成以下项目。每项记录“通过 / 失败 / 未测”，失败时记录 Zotero 版本、系统、操作步骤和错误详情。

- [ ] **升级与重启**：从当前版本安装候选 XPI，插件版本显示 `5.0.0-beta.1`。已有模型端点、提示词、MinerU 设置、任务记录和笔记仍可用。完整退出 Zotero 后重新启动，插件可正常打开。
- [ ] **启停与窗口**：关闭并重新打开主窗口，禁用后重新启用插件。资料库工具栏、Reader 工具栏、侧栏和状态列各出现一次；设置和摘要仍可使用。
- [ ] **教程导航**：重新打开教程，经历主窗口与插件窗口切换、任务队列已经打开、关闭并重开插件窗口。高亮跟随正确目标，步骤不跳过、不重复前进。
- [ ] **教程选择 PDF**：先选有 PDF 的论文 A，再切到无 PDF 的论文 B、笔记、非 PDF 附件或清空选择。按钮应变为不可用；即使立即点击，也不能把 A 加入队列。再选另一篇有 PDF 的论文 C，只提交 C；直接选 PDF 子附件时提交其父条目。
- [ ] **教程任务复用与跟踪**：重复选择已有摘要任务的论文不会产生重复任务；明确提交后，在资料库切换选择，教程仍跟踪刚才提交的任务。关闭自动扫描时，教程的明确确认仍可生成摘要，并且不会开启全库自动扫描。
- [ ] **小窗口设置**：默认大小和缩小窗口各走一遍教程。“自动精读”选项能滚动到、能看清，教程展示它时不会擅自开启；设置页最底部的控件可操作。
- [ ] **侧栏与滚动**：用一篇较长的 AI 笔记测试，缩小主窗口、收窄侧栏并切换条目。笔记最后一行和底部按钮始终可达；在内部滚动区到顶/到底后，滚轮能正确交给外层，不出现整块内容被裁掉。
- [ ] **PDF 正常路径**：分别用一篇已有全文缓存的 PDF、一篇刚导入的 PDF 和中文路径下的 PDF 生成摘要，确认内容来自当前论文、任务可完成并保存笔记。验收 Zotero 6 时重点重复中文路径场景。
- [ ] **PDF 失败与取消**：使用无法提取文本的文件测试错误提示和“复制错误详情”。本地提取失败应给出诊断，不反复轮换模型端点重试；提取或生成期间点击取消，任务停止，不产生误报成功的笔记。
- [ ] **请求头与端点**：对已配置的代理/平台设置所需自定义请求头，测试连接、获取模型列表、摘要和聊天。切换到第二个端点后配置不串用；清空请求头可恢复原有请求；错误 JSON 会被明确拒绝。
- [ ] **MinerU**：测试实际使用的官方或自建服务。自建服务按所用的 `file-parse`、`v1` 或 `v4` 格式配置，确认 OCR 文字/图片可进入摘要；服务错误、超时和取消有反馈。切换回官方服务时使用官方配置。没有环境的格式记为未测。
- [ ] **批量队列**：先暂停执行，再批量加入约 100～500 个条目，观察窗口是否仍能响应、数量是否准确、重复确认是否去重。只恢复少量任务验证执行；重启后任务列表保留，删除任务后不会被另一窗口刷新恢复。
- [ ] **附件过滤**：混合选择有效 PDF、缺失的链接文件、尚未下载的附件、无可用内容条目后批量入队。只加入可处理条目，跳过数量有反馈；全部无效时不虚报成功。扫描后再移走一个附件，确认入队时会再次检查。
- [ ] **主流程回归**：至少完成普通摘要、多轮精读、追问、表格填充、综述、脑图、一图总结各一次，并检查产物保存。对带公式的笔记检查渲染、Markdown 导出和 DOCX 导出。
- [ ] **Agent**：运行一次检索并阅读论文的任务，验证连续追问。只读模式不修改资料库；需要写入的操作遵守确认，取消/拒绝后不执行。若使用自定义请求头或 MinerU，覆盖相应 Agent 路径。
- [ ] **中文和英文界面**：切换 Zotero 语言后检查教程、设置、任务错误、侧栏及 Reader 按钮，无原始翻译键、乱码或布局截断。

## 发布条件

人工验收通过后，在同一份通过验收的 dev 提交上执行现有发布流程，目标 tag 为 `v5.0.0-beta.1`，GitHub Release 应标记为预发布。本次准备工作不创建或推送版本 tag，也不发布 Release。

如测试中继续修改代码，应重新构建候选包并复测受影响项目，再由维护者发布。
