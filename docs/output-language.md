# 输出语言（AI 总结 / AI 精读 / 表格 / 综述 / 侧边栏对话）

> 分别选择内置提示词模板的语言和生成内容的语言。

## 在哪里设置

打开设置中的 AI 精读、AI 总结或表格提示词页面。

- **默认提示词语言**：内置模板可跟随 Zotero 界面语言，也可固定使用中文或英文。

- **输出语言**：自由填写目标语言，例如 `简体中文`、`繁體中文`、`English`、`日本語`、`Français`、`Español`。
  - 留空 = **不干预**：完全以你自己的提示词为准（与未启用该功能时一致）。
  - 例如，默认提示词语言选中文，输出语言填 `English`，即可用中文模板生成英文答案。
- **学科口径**：让生成的翻译/写作规范贴合学科，可选
  - 通用（基础版）
  - 理科（数理化生 / 地学 / 材料）
  - 工科（机械 / 电子 / 计算机 / 土木 / 化工）
  - 艺术（美术 / 音乐 / 影视 / 设计 / 建筑）
  - 商科（经济 / 金融 / 管理 / 会计 / 营销）
  - 人文（哲学 / 历史 / 文学 / 社会学 / 教育学）
  - 医学（临床 / 基础 / 药学 / 公卫 / 护理）
  - 法学（法理 / 民刑 / 公法 / 国际法）

## 影响范围

| 功能                      | 是否受控 | 说明                                                                  |
| ------------------------- | -------- | --------------------------------------------------------------------- |
| AI 总结                   | ✅       | 单篇总结、多模型总结                                                  |
| AI 精读                   | ✅       | 逐章精读与重点追问各轮                                                |
| 表格填充 / 表格综述       | ✅       | 表头维度填充与跨文献综述                                              |
| 文献综述                  | ✅       | 分类多文献综述                                                        |
| 思维导图                  | ✅       | 精简导图文本                                                          |
| 侧边栏对话 / 追问         | ✅       | 与论文的问答与追问                                                    |
| 精读的“章节规划”请求      | ❌       | 必须返回 JSON，不能注入自然语言要求                                   |
| 一图总结（image-summary） | ❌       | 输出需被图像生成器结构化解析                                          |
| AI 管家智能体             | 部分     | 智能体对话轮次按提问作答；`read_paper` 工具生成的论文分析使用输出语言 |

## 它是如何生效的

1. 设置写入偏好 `extensions.zotero.aiButler.outputLanguage` 与
   `extensions.zotero.aiButler.outputLanguageDomain`。
2. 每次请求在 LLM 层统一注入一段 `<output-language>` 规则
   （单轮提示词追加在末尾，多轮对话只写入第一条 `user` 消息，幂等）。
3. 规则由“学科口径 + 翻译规范”动态生成，包含：
   - 忠实性要求：不得增删事实、改写结论或臆测；无法确定时保留原文并括注。
   - 术语与体例：各学科不同的术语、缩写、单位、引用与文体规则。
   - 结构对齐：标题层级、列表、表格、图表题注、编号、脚注。
   - 原样保留：公式与符号、单位、代码与标识符、数据集/模型名称、引文标记（`[1]`、`@key`、`\cite{}`）、DOI 与 URL。
   - 术语一致性：同一术语全文统一，首次出现可写「译名（原文）」。

## 注意事项

- 只影响**新发起**的任务；已生成的笔记不会自动重写。需要改写旧笔记请重新生成。
- 自定义提示词不会被覆盖：规则是“追加约束”，你的提示词文本保持原样。
- 输出语言优先于提示词中冲突的语言要求。要按提示词指定的语言生成，请清空输出语言。
- 设置导出和导入会保留这三项偏好。恢复默认后，模板跟随 Zotero 界面语言，输出语言留空，学科口径为「通用」。
